# Конструктор тестов

## Назначение
Приложение предназначено для создания и прохождения тестов.  
Преподаватель может создавать тесты, добавлять вопросы и варианты ответов,  
а студенты — проходить тесты и получать оценку.

## Целевая аудитория
Преподаватели и студенты учебных заведений.

## Предметная область
Образование, онлайн-тестирование.

## Основные сущности
- Преподаватель
- Тест
- Вопрос
- Вариант ответа

## Основные функции
1. **Создание теста** — ввод названия теста, имени автора и даты.
2. **Добавление вопроса** — ввод текста вопроса, вариантов ответов и номера правильного ответа.
3. **Прохождение теста** — ответ на вопрос и проверка правильности.
4. **Вывод результата** — отображение вердикта (верно/неверно) и правильного ответа.

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей (преподавателей и студентов);
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
